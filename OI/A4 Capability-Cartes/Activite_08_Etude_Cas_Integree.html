🏭 Étude de Cas Intégrée : Ligne de Convoyeur

Mettez en œuvre TOUTES vos compétences SPC dans un scénario industriel complet : de l'analyse de normalité à la mise en place des cartes de contrôle et au plan d'action.

⏱️ 90 min | 👥 Travail en binôme | 📁 Fichier : SPC-15-convoyeur.csv

📋 Le scénario

Vous êtes technicien qualité dans une usine d'assemblage. Votre ligne de convoyeur utilise deux machines (A et B) pour produire un sous-ensemble critique. Vous disposez de données de contrôle sur deux caractéristiques :

  • Z-écart : écart dimensionnel (en µm) par rapport à la cible
  • Z : dimension mesurée (en µm)
📏 Spécification Z-écart : LSI = 50 µm  |  LSS = 350 µm
📏 Spécification Z : LSI = 100 µm  |  LSS = 300 µm
📊 Structure : Sous-groupes de 4 mesures, 2 machines

Travaille sur la variable Z-écart

👤 Binôme B

Travaille sur la variable Z

Étape 1 — Analyse exploratoire (20 min)

Statistiques descriptives & normalité

  1. Ouvrir SPC-15-convoyeur.csv et identifier les colonnes (groupe, Z-écart, machine, Z)
  2. Séparer les données par machine (A et B)
  3. Pour votre variable assignée, calculer : moyenne, écart-type, min, max
  4. Construire l'histogramme (global puis par machine)
  5. Vérifier la normalité

❓ Livrable 1

Les distributions des deux machines sont-elles similaires ? Y a-t-il un décalage de centrage entre machine A et machine B ?

Étape 2 — Étude de capabilité (20 min)

Calcul des indices Cp/Cpk/Pp/Ppk

  1. Calculer Cp, Cpk, Pp, Ppk pour chaque machine séparément
  2. Calculer Cp, Cpk, Pp, Ppk pour les deux machines combinées
  3. Comparer les résultats

💡 Question piège : Pourquoi les indices combinés sont-ils probablement moins bons que ceux de chaque machine séparément ? (Indice : que se passe-t-il quand on mélange deux distributions centrées différemment ?)
Étape 3 — Carte de contrôle (25 min)

Construction et interprétation

  1. Construire une carte X̄-R sur les données combinées
  2. Observer : y a-t-il des signaux d'alarme ?
  3. Construire deux cartes séparées (une pour machine A, une pour machine B)
  4. Comparer l'interprétation

❓ Livrable 3

La carte combinée montre-t-elle un pattern de « mélange » (règle 6) ? Les cartes séparées sont-elles sous contrôle ? Quelle leçon en tirez-vous sur le regroupement des données ?

Étape 4 — Plan d'action & restitution (25 min)

Décision et communication

Sur la base de votre analyse complète, proposez un plan d'action au responsable de production :

  1. Le procédé est-il capable ? Si non, quelle machine pose problème ?
  2. Faut-il séparer la surveillance des deux machines ?
  3. Quelle fréquence d'échantillonnage recommandez-vous ?
  4. Quelles règles d'interprétation sont les plus pertinentes ici ?
