## 🗂️ Organisation des Fichiers

La collection est organisée de deux façons complémentaires :

### 1️⃣ **Fichier Central** : `Jeux_de_Role_Resolution_Problemes.md`

Ce fichier contient **toutes les descriptions** des 6 jeux de rôle dans un seul document :

- Section 1 : JdR n°1 (QRQC)
- Section 2 : JdR n°2 (8D)  
- Section 3 : JdR n°3 (5 Pourquoi)
- Section 4 : JdR n°4 (Pareto)
- Section 5 : JdR n°5 (Poka-Yoke)
- Section 6 : JdR n°6 (Kaizen)

📖 **Utilisez ce fichier pour** : Avoir une vue d'ensemble rapide des 6 scénarios

---

### 2️⃣ **Répertoires Individuels** : Un dossier par jeu de rôle

Chaque jeu de rôle possède maintenant son propre répertoire avec :

- Un README explicatif
- Un kit d'indices complet

## 🔍 Comment Trouver Ce Dont Vous Avez Besoin ?

### Vous voulez

→ Lisez `Guide_Formateur_Jeux_de_Role.md` (méthodologie d'animation)

### Étape 2 : Préparer la session

Allez dans `JdR1_QRQC/` et ouvrez `Kit_Indices_JDR1_QRQC.md`

- Indice 1 : Photo composant défectueux

- Indice 3 : Gamme opératoire

- Indice 7 : Photo détrompeur (à ne révéler que si Genba)
- etc.

### Étape 4 : Animer

Suivez le déroulé pédagogique dans le kit d'indices

## ❓ Questions Fréquentes

**Q : Pourquoi y a-t-il `Jeux_de_Role_Resolution_Problemes.md` ET des dossiers séparés ?**

R : Le fichier central donne une vue d'ensemble rapide. Les dossiers séparés contiennent les kits d'indices détaillés (10-20 pages chacun). C'est comme avoir un menu (fichier central) et les recettes complètes (dossiers).

**Q : Où sont les images (photos des composants, etc.) ?**

R : Les chemins complets des images sont indiqués dans chaque kit d'indices. Elles sont dans le dossier brain de la session.

**Q : Puis-je modifier les scénarios ?**

R : Absolument ! Les fichiers `.md` sont faits pour être adaptés à votre contexte industriel.
