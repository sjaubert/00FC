# 🎭 JdR n°1 : Le "QRQC" de Survie

**Méthode** : QRQC (Quick Response Quality Control)  
**Niveau** : ⭐ Débutant  
**Durée** : 60 min (45 min jeu + 15 min débriefing)  
**Joueurs** : 4 personnes

---

## 🎬 Le Pitch

Une ligne d'assemblage de cartes électroniques détecte un composant monté à l'envers. Le client attend la livraison pour ce soir à 18h00. La tension monte. Le chef d'équipe est tenté de faire un "tri" et de continuer la production.

## 🎯 Le Piège

Si l'équipe ne fait pas le "San Gen Shugi" (aller sur le vrai lieu, voir la vraie pièce, constater la réalité), ils ne verront pas que le **détrompeur mécanique est cassé**. Ils risquent d'accuser l'opérateur d'avoir fait une erreur, alors que c'est le système qui est défaillant.
