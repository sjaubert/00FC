## 🎯 Vue d'Ensemble

Cette collection comprend **6 jeux de rôle pédagogiques** conçus pour former aux principales méthodes de résolution de problèmes utilisées dans l'industrie.

### Objectifs Globaux

- ✅ Maîtriser les outils qualité (QQOQCP, Ishikawa, Pareto, 5 Pourquoi, 8D)
- ✅ Adopter les principes Lean (Genba, Auto-Qualité, Poka-Yoke, Kaizen)
- ✅ Développer une culture d'analyse méthodique
- ✅ Travailler efficacement en équipe pluridisciplinaire

### Public Cible

- Opérateurs de production
- Techniciens de maintenance
- Responsables qualité
- Chefs d'équipe et superviseurs
- Ingénieurs méthodes

### Prérequis

- Aucun pour les JdR n°1, 3, 4
- Connaissances de base en qualité pour JdR n°2, 5, 6

## 📖 Catalogue des Jeux de Rôle

### 🎭 JdR n°1 : Le "QRQC" de Survie

**📁 Fichiers** :

- Description : `Jeux_de_Role_Resolution_Problemes.md` (Section 1)
- Kit d'indices : `Kit_Indices_JDR1_QRQC.md`

**⏱️ Durée** : 40-45 min + 15-20 min débriefing

**🎯 Méthode enseignée** : QRQC (Quick Response Quality Control)

**🔧 Outils** :

- QQOQCP
- Principe des 3 Réels (San Gen Shugi)
- Auto-Qualité (arrêt de production)

**📋 Pitch** :
Une ligne d'assemblage de cartes électroniques détecte un composant monté à l'envers. Le client attend la livraison pour ce soir. L'équipe doit décider : arrêter ou continuer ?

**👥 Personnages** : 4 joueurs

- L'Opérateur
- Le Chef d'Équipe
- Le Technicien Qualité
- Le Saboteur (Formateur)

**🎓 Objectif pédagogique** :

- Aller sur le terrain (Genba)
- Ne pas céder à la pression des délais
- Chercher la cause racine systémique

**💡 Piège** :
Le détrompeur mécanique est cassé, mais cette information n'est révélée que si l'équipe va physiquement inspecter le poste.

**📊 Niveau** : ⭐ Débutant (bon pour démarrer la formation)

**🖼️ Visuels inclus** :

- Photo composant défectueux
- Photo composant correct
- Photo détrompeur cassé

### 🎭 JdR n°2 : La "Méthode 8D" en Crise

**📁 Fichiers** :

- Description : `Jeux_de_Role_Resolution_Problemes.md` (Section 2)
- Kit d'indices : *(À créer - template disponible)*

**⏱️ Durée** : 60 min + 45 min débriefing

**🎯 Méthode enseignée** : 8D (8 Disciplines)

**🔧 Outils** :

- Diagramme 8D
- Ishikawa (5M)
- 5 Pourquoi
- Plan d'actions

**📋 Pitch** :
Un client majeur retourne pour la 3ème fois des lots de pièces usinées hors tolérances. L'équipe doit appliquer la méthode 8D de manière rigoureuse.

**👥 Personnages** : 5 joueurs

- Le Leader 8D
- Le Responsable Production
- Le Méthodes/Process
- Le Qualiticien
- Le Perturbateur (Formateur)

**🎓 Objectif pédagogique** :

- Suivre les 8 disciplines sans sauter d'étapes
- Analyser méthodiquement (D4-D5) avant d'agir (D6)
- Documenter pour éviter la récurrence

**💡 Piège** :
Le problème est intermittent car lié à un des 3 tours (dilatation thermique), mais l'équipe aura tendance à vouloir "réparer vite" sans analyser.

**📊 Niveau** : ⭐⭐⭐ Avancé (méthode complexe)

### 🎭 JdR n°3 : Le "5 Pourquoi" du Mystère

**📁 Fichiers** :

- Description : `Jeux_de_Role_Resolution_Problemes.md` (Section 3)
- Kit d'indices : *(À créer)*

**⏱️ Durée** : 40 min + 20 min débriefing

**🎯 Méthode enseignée** : 5 Pourquoi

**🔧 Outils** :

- Méthode des 5 Pourquoi
- Observation terrain
- Ishikawa (support)

**📋 Pitch** :
Des arrêts intempestifs d'un convoyeur (3-4 fois/semaine). Le moteur a été changé 2 fois mais le problème persiste.

**👥 Personnages** : 4 joueurs

- L'Animateur 5 Pourquoi
- Le Technicien Maintenance
- L'Opérateur Production
- Le Fausseur (Formateur)

**🎓 Objectif pédagogique** :

- Creuser en profondeur (minimum 5 itérations)
- Ne pas s'arrêter aux symptômes
- Éviter les causes techniques complexes si cause simple existe

**💡 Piège** :
La vraie cause est simple (eau de nettoyage infiltrée dans coffret électrique mal fermé) mais l'équipe va naturellement chercher des causes techniques complexes.

**📊 Niveau** : ⭐⭐ Intermédiaire

### 🎭 JdR n°4 : Le "Pareto" sous Pression

**📁 Fichiers** :

- Description : `Jeux_de_Role_Resolution_Problemes.md` (Section 4)
- Kit d'indices : *(À créer)*

**⏱️ Durée** : 45-50 min + 20-25 min débriefing

**🎯 Méthode enseignée** : Pareto (Loi 80/20)

**🔧 Outils** :

- Diagramme de Pareto
- Feuille de relevé
- Plan d'action priorisé

**📋 Pitch** :
Le taux de rebuts de l'atelier peinture a explosé (12% au lieu de 3%). Défauts multiples : coulures, poussières, manques, mauvaises teintes. La direction exige un plan pour demain.

**👥 Personnages** : 4 joueurs

- Le Responsable Qualité
- Le Chef d'atelier Peinture
- Le Technicien Process
- Le Brouilleur (Formateur)

**🎓 Objectif pédagogique** :

- Prioriser (20% causes = 80% effets)
- Construire un Pareto de manière méthodique
- Résister à la tentation de tout traiter en même temps

**💡 Piège** :
75% des rebuts viennent d'un seul défaut (poussières), causé par un filtre de cabine bouché (oubli maintenance préventive).

**📊 Niveau** : ⭐⭐ Intermédiaire

**🖼️ Visuels inclus** :

- Diagramme Pareto (exemple)

### 🎭 JdR n°5 : Le "Poka-Yoke" Salvateur

**📁 Fichiers** :

- Description : `Jeux_de_Role_Resolution_Problemes.md` (Section 5)
- Kit d'indices : `Kit_Indices_JDR5_Poka_Yoke.md`

**⏱️ Durée** : 45-50 min + 20-25 min débriefing

**🎯 Méthode enseignée** : Poka-Yoke (Systèmes anti-erreur)

**🔧 Outils** :

- Grille d'analyse Poka-Yoke
- Matrice coût/efficacité
- Prototypage rapide

**📋 Pitch** :
15% de défauts (joints toriques inversés) malgré formations répétées. Les opérateurs sont compétents mais l'erreur persiste. Budget : 500€ max.

**👥 Personnages** : 4 joueurs

- L'Ingénieur Méthodes
- L'Opérateur Expérimenté
- Le Technicien Maintenance
- Le Minimaliste (Formateur)

**🎓 Objectif pédagogique** :

- Concevoir une solution systémique (pas former encore)
- Privilégier solutions simples et robustes
- Appliquer le principe "rendre l'erreur impossible"

**💡 Piège** :
L'équipe va chercher des solutions high-tech coûteuses alors que la solution optimale est simple : bacs colorés + couvercles rainurés + séparation spatiale (115€).

**📊 Niveau** : ⭐⭐ Intermédiaire

**🖼️ Visuels inclus** :

- Joints toriques (rouge vs noir)
- Poste désorganisé
- Solution Poka-Yoke (exemple)

## 🎓 Comment Utiliser Cette Collection

### Pour un Formateur Débutant

1. **Commencer par lire** :
   - Ce document (Index) pour vue d'ensemble
   - `Guide_Formateur_Jeux_de_Role.md` pour méthodologie

2. **Choisir un JdR simple** : n°1 (QRQC) ou n°4 (Pareto)

3. **Préparer le kit** :
   - Lire le kit d'indices en détail
   - Imprimer les documents
   - Tester mentalement le déroulé

4. **Animer et débriefer** en suivant le guide

5. **Améliorer** : noter ce qui a fonctionné/pas fonctionné

---

### Pour un Formateur Expérimenté

- **Adapter** les scénarios à votre contexte industriel
- **Créer** de nouveaux kits d'indices pour JdR n°2, 3, 4, 6
- **Mixer** les méthodes (ex: utiliser 5 Pourquoi + Pareto sur même cas)
- **Complexifier** : ajouter des contraintes, moins d'indices

## 🏆 Bonnes Pratiques Identifiées

### Ce qui Fonctionne Très Bien ✅

1. **Pression du temps** : Chronomètre visible crée l'urgence réaliste
2. **Indices progressifs** : Ne pas tout donner d'un coup, force la recherche
3. **Rôle du "perturbateur"** : Oriente vers mauvaises pistes si méthode pas appliquée
4. **Objets physiques** : Vrais composants, joints → engagement ++++
5. **Lien avec expérience** : Demander "Et vous, ça vous est déjà arrivé ?"

### Ce qui Fonctionne Moins ❌

1. ❌ Groupes > 5 personnes (dilution responsabilité)
2. ❌ Débriefing < 15 min (frustration, pas assez d'apprentissage)
3. ❌ Tous les indices d'un coup (pas de suspense, moins engaging)
4. ❌ Pas de chrono (pas de pression, discussions infinies)
5. ❌ Formateur donne réponse trop vite (pas d'apprentissage actif)
