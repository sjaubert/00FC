## 🎯 SOLUTION ATTENDUE (Pour le Formateur)

### Application de la Méthode des 5 Pourquoi

**PROBLÈME** : Le convoyeur s'arrête de manière intempestive 3-4 fois par semaine

**POURQUOI 1** : Pourquoi le convoyeur s'arrête-t-il ?
→ **Réponse** : Le relais thermique se déclenche (protection sécurité)

**POURQUOI 2** : Pourquoi le relais thermique se déclenche-t-il ?
→ **Réponse** : Il détecte une anomalie électrique (faux court-circuit)

**POURQUOI 3** : Pourquoi y a-t-il une anomalie électrique ?
→ **Réponse** : De l'eau s'est infiltrée dans le coffret électrique

**POURQUOI 4** : Pourquoi de l'eau s'est-elle infiltrée ?
→ **Réponse** : Le joint de porte du coffret est usé + eau de nettoyage

**POURQUOI 5** : Pourquoi le coffret reçoit-il de l'eau de nettoyage ?
→ **CAUSE RACINE** : La procédure de nettoyage au jet d'eau près d'un coffret électrique non étanche n'est pas sécurisée

### Ishikawa (Support) - Causes Secondaires

**5M** :

- **MATÉRIEL** : Joint de coffret usé (vieux modèle)
- **MÉTHODE** : Procédure nettoyage inadaptée (jet d'eau trop près équipements électriques)
- **MILIEU** : Coffret positionné trop bas (50cm du sol, zone d'aspersion)
- **MAIN D'ŒUVRE** : Équipe nettoyage non formée aux risques électriques
- **MOYEN** : Pas de protection du coffret pendant nettoyage

### Actions Correctives

**IMMÉDIAT** (Coût faible, délai court) :

1. **Changer le joint du coffret** → 50€, 1h
2. **Signaler zone "Pas d'eau"** autour coffret → 0€, 30 min
3. **Former équipe nettoyage** → 0€, 1h

**MOYEN TERME** (Amélioration durable) :
4. **Installer coffret IP65 (étanche)** → 400€, 2h
5. **Modifier procédure nettoyage** (balayage humide au lieu de jet) → 0€

**LONG TERME** (Prévention) :
6. **Audit de tous les coffrets atelier** → Identifier autres risques
7. **Programme remplacement coffrets non-étanches** → Budget préventif

### Coût/Bénéfice

**Coût solution complète** : ~500€  
**Économie** : 15 000€/mois de pertes évitées  
**ROI** : Rentabilisé en 1 jour ! ✅

## 📝 Points de Débriefing

### Pièges Fréquents ❌

1. **S'arrêter au symptôme** : "C'est le relais thermique défaillant" → Changer le relais (erreur !)
2. **S'arrêter à la cause technique** : "C'est le joint usé" → Changer le joint (incomplet !)
3. **Ne pas aller sur le terrain** : Rester en salle de réunion → Ne jamais voir le coffret
4. **Accepter les réponses de surface** : "Ça arrive au hasard" → Ne pas creuser
5. **Solution technique uniquement** : Changer coffret sans modifier procédure nettoyage

### Comportements Recherchés ✅

1. ✅ **Aller sur le terrain** (Genba) → Observer le coffret, la zone
2. ✅ **Interroger tous les acteurs** (maintenance, production, nettoyage, électricien)
3. ✅ **Chercher les corrélations** (croiser planning arrêts / nettoyage)
4. ✅ **Creuser avec les 5 Pourquoi** jusqu'à la vraie cause racine
5. ✅ **Solution systémique** (technique + organisationnel + formation)

### Messages Clés 💡

> "La cause racine n'est PAS le joint usé, c'est l'organisation qui permet qu'un coffret électrique soit arrosé !"

> "Changer 2 fois le moteur pour 50€ de joint... C'est ça, ne pas chercher la cause racine !"

> "Si vous ne voyez pas de pattern, c'est que vous n'avez pas assez de données. Creusez !"

> "Le 5ème POURQUOI est souvent inconfortable car il pointe vers un problème d'organisation, pas de technique."
