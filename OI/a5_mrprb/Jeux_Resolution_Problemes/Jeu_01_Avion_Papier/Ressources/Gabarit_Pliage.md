# GABARIT DE PLIAGE - AVION EN PAPIER

## Modele Standard "Dart"

### Etape 1 : Pli central

```
+---------------------------+
|                           |
|                           |
|                           |
|                           |
|                           |
|             |             |
|             |             |
|             |             |
|             |             |
|             |             |
|                           |
+---------------------------+

Plier en deux dans le sens de la longueur
Bien marquer le pli
```

### Etape 2 : Plis des coins superieurs

```
        /\
       /  \
      /    \
     /      \
    /        \
   /          \
  /            \
 /              \
|                |
|                |
|                |
|                |
|                |
+----------------+

Plier les deux coins superieurs vers le pli central
Les bords doivent se toucher au centre
```

### Etape 3 : Plis exterieurs

```
      /\
     /  \
    /    \
   /      \
  /        \
 /          \
|            |
|            |
|            |
|            |
|            |
|            |
+------------+

Plier les bords exterieurs vers le pli central
La pointe doit rester bien alignee
```

### Etape 4 : Formation des ailes

```
Vue de face apres pliage des ailes :

       /\
      /  \
     /    \
    /      \
   /        \
  /          \
 /            \
/_____________\

Les deux ailes sont symetriques
Angle d'environ 20 degres par rapport a l'horizontale
```

### Etape 5 : Verification finale

```
Vue de dessus :

         ^
        /|\
       / | \
      /  |  \
     /   |   \
    /    |    \
   /     |     \
  /      |      \
 /       |       \
/________|________\

Verifier :
- Symetrie parfaite des ailes
- Pli central bien marque
- Nez pointu et solide
```

---

## Criteres de conformite

| Critere | Standard | Tolerance |
|---------|----------|-----------|
| Longueur aile gauche | Egale a droite | +/- 5mm |
| Angle des ailes | 20 degres | +/- 5 degres |
| Pli central | Rectiligne | Aucune deviation |
| Nez | Pointu | Non ecrase |
| Distance de vol | 3 metres minimum | - |
