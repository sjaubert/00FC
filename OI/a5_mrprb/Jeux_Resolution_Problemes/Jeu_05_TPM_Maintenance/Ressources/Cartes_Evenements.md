# CARTES EVENEMENTS - TPM

## Instructions

Melanger ces cartes et en tirer une par tour (toutes les 3-4 semaines).
L'evenement s'applique immediatement.

---

## Carte 1 - URGENCE CLIENT

```
+----------------------------------------+
|                                        |
|  EVENEMENT : URGENCE CLIENT            |
|                                        |
|  Votre client principal a une          |
|  commande urgente.                     |
|                                        |
|  EFFET :                               |
|  Production demandee x 1.5             |
|  cette semaine                         |
|                                        |
|  Bonus si objectif atteint : +2000 EUR |
|  Malus si echec : -3000 EUR            |
|                                        |
+----------------------------------------+
```
