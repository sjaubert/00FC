Question-choc :

L'histoire de Kodak

En 2006, Kodak employait 80 000 personnes. En 2012 : faillite.

Pourquoi ? Ils ont ignoré ce que voulaient leurs clients (photo numérique).

Nokia, Blockbuster, Toys 'R' Us... même sort.

La relation client est VITALE.

C. La performance industrielle : QCD

EXERCICE : Le Triptyque Impossible

Vous êtes chef d'entreprise. Un client vous demande :

  • Qualité exceptionnelle (0 défaut)
  • Prix très bas (-30%)
  • Livraison demain

En binômes : Proposez une stratégie

Triangle QCD

       QUALITÉ
       /      \
      /        \
     /  QCD  \
    /          \
  COÛTS --- DÉLAIS

Exemples sectoriels :

  • Luxe (Hermès) : Qualité max, délais longs acceptés, coûts élevés
  • Low-cost (Ryanair) : Coûts min, qualité acceptable, délais courts
  • Urgence (pompiers) : Délais min, qualité max, coûts non prioritaires

Indicateurs clés :

Dimension Indicateurs
Qualité Taux de rebut, taux de retour client, conformité
Coûts Prix de revient, productivité, coût main d'œuvre
Délais Lead time, taux de service, respect des plannings

Message : Même une tâche simple est un PROCESSUS (suite d'étapes ordonnées)

A. L'approche processus

"Un processus, c'est quoi selon vous ?"

Définition :

Succession d'activités qui transforment des ENTRÉES en SORTIES pour créer de la VALEUR

Schéma SIPOC

FOURNISSEURS → ENTRÉES → PROCESSUS → SORTIES → CLIENTS
(Suppliers)   (Inputs)  (Process)  (Outputs) (Customers)

Exemple concret : Fabrication d'une baguette

Étape Fournisseur Entrée Processus Sortie Client
1 Meunier Farine, eau, sel, levure Pétrissage Pâte Boulanger
2 Boulanger Pâte Façonnage Baguettes crues Four
3 Four Baguettes crues Cuisson 15 min à 240°C Baguettes cuites Consommateur

B. Valeur Ajoutée vs Non-Valeur Ajoutée

Révélation :

"Dans une usine classique, seulement 5 à 10% du temps crée de la VRAIE valeur pour le client !"

"Le reste du temps, c'est quoi ?"

Définitions :

  • VA (Valeur Ajoutée) : Activité qui TRANSFORME le produit de façon visible pour le client
  • NVA (Non-Valeur Ajoutée) : Activité qui ne transforme PAS mais coûte du temps/argent

MODULE 4 : Introduction au Lean Manufacturing

"Alors, qu'avez-vous observé à la cantine ?"

L'histoire de Toyota

1950, Japon en ruines après-guerre. Toyota n'a pas d'argent pour de grosses machines comme Ford.

Solution ? Éliminer TOUT gaspillage.

Résultat : Toyota devient n°1 mondial.

Principes du Lean

Lean = Maigre = Éliminer le gras (les gaspillages)

Les 5 principes du Lean :

  1. Définir la VALEUR du point de vue du client
  2. Identifier la CHAÎNE de valeur
  3. Créer un FLUX continu
  4. Produire en FLUX TIRÉ (à la demande)
  5. Viser la PERFECTION (amélioration continue)

"Selon vous, quel est LE principe le plus important ?"

OUTIL 1 : Les 5S

S japonais S français Objectif
Seiri Trier Éliminer l'inutile
Seiton Ranger Une place pour chaque chose
Seiso Nettoyer Inspecter en nettoyant
Seiketsu Standardiser Règles visuelles claires
Shitsuke Respecter Pérenniser les bonnes pratiques

ATELIER PRATIQUE : 5S sur table

Étapes :

  • TRIER : Éliminez tout ce qui ne sert pas TOUS LES JOURS
  • RANGER : Organisez pour que tout soit accessible en moins de 30 secondes
  • NETTOYER : Le nettoyage = occasion d'inspecter
  • STANDARDISER : Créez un panneau visuel "Standard 5S"
  • RESPECTER : Définissez les audits réguliers

Questions de débriefing :

  • "Combien de temps pour trouver un stylo AVANT ?"
  • "Et APRÈS ?"
  • "Gain de temps sur 1 an ?"

Bénéfices des 5S :

  • Gain de temps : -20 à 30%
  • Sécurité : -50% d'accidents
  • Qualité : -40% de défauts
  • Bien-être : environnement agréable

OUTIL 2 : Management visuel

Principe : "L'information doit être visible en 5 secondes à 5 mètres"

Exemples de management visuel :

  • Tableau de performance : Objectif / Réalisé / Problèmes
  • Andon (voyant lumineux) : Vert = OK, Orange = ralentissement, Rouge = arrêt
  • Marquage au sol : Circulation / Stockage / Zones interdites

"Pourquoi afficher les problèmes en rouge en grand ? On pourrait les cacher, non ?"

OUTILS 3 & 4 : TPM et SMED

TPM - Total Productive Maintenance

Analogie : "Votre voiture : vous attendez qu'elle tombe en panne ou vous faites la vidange ?"

Concept :

  • Opérateurs = 1ers maintenanciers
  • Objectif : Zéro panne non planifiée

Exemple : Usine Toyota → Taux de panne : -40%

SMED - Changement de série rapide

Démonstration : Changement de roue Formule 1 (2 secondes !)

Application industrielle :

Usine Renault : changement de moule en presse

  • AVANT SMED : 4 heures
  • APRÈS SMED : 8 minutes
  • Gain : + 30 changements par mois = + flexibilité

Quiz rapide :

  1. "Que signifie Lean ?"
  2. "Citez les 5S"
  3. "Pourquoi afficher les problèmes ?"

MODULE 5 : L'Amélioration Continue et la Résolution de Problèmes

Énigme :

"Une machine tombe en panne 3 fois par semaine. Que faites-vous ?"

Principe Toyota : Quand une machine tombe en panne, c'est une OPPORTUNITÉ d'amélioration.

L'esprit Kaizen

KAI (改) = Changement

ZEN (善) = Meilleur

→ Amélioration continue

Philosophie :

  • Améliorer chaque jour un peu (vs révolution)
  • Tout le monde peut proposer des améliorations
  • Petit changement + constance = énorme impact

Exemple inspirant : Usine Toyota Georgetown (USA)

  • 1 million d'idées d'amélioration proposées en 2019
  • 99% mises en œuvre
  • Gain moyen par idée : 70$
  • Total : 70 millions $ économisés !

"Si vous travaillez 35 ans dans une usine, combien d'améliorations pouvez-vous apporter ?"

Culture de l'amélioration vs culture du blâme

Culture du blâme Culture Kaizen
"Qui a fait l'erreur ?" "Pourquoi le système a permis l'erreur ?"
Cacher les problèmes Révéler les problèmes
Punir Apprendre
Peur Confiance

Méthodologie de résolution

Les étapes universelles :

  1. OBSERVER : Aller voir le problème réel (Gemba)
  2. DÉCRIRE : Faits, données, pas d'opinion
  3. ANALYSER : Chercher la cause racine
  4. AGIR : Mettre en place une solution
  5. VÉRIFIER : Mesurer l'efficacité
  6. STANDARDISER : Éviter que ça se reproduise

OUTIL : Les 5 Pourquoi

Principe : Poser 5 fois "Pourquoi ?" pour trouver la cause racine

Exemple célèbre - Monument Jefferson (Washington)

Problème : La pierre du monument se détériore

  1. Pourquoi ? → Parce qu'on le nettoie trop souvent
  2. Pourquoi on nettoie souvent ? → Beaucoup de fientes d'oiseaux
  3. Pourquoi autant d'oiseaux ? → Ils mangent les araignées
  4. Pourquoi autant d'araignées ? → Elles mangent les insectes attirés par les éclairages
  5. Pourquoi ces insectes sont attirés ? → Les lampes sont allumées tôt le soir

Solution : Allumer les lampes 1h plus tard

Résultat : Nettoyage divisé par 4 !

EXERCICE PRATIQUE : Le mystère des pièces défectueuses

Contexte : Atelier d'usinage de pièces métalliques

Problème : Depuis 2 semaines, 15% des pièces sont hors cote (trop larges de 0,2mm)

Perte : 5000€/semaine

Données fournies :

  • Machine neuve, installée il y a 1 mois
  • Opérateur expérimenté (10 ans d'ancienneté)
  • Contrôles qualité OK jusqu'à il y a 2 semaines
  • Température atelier : 25°C (été)
  • Matière première : même fournisseur depuis 5 ans

Travail en équipe :

  1. Appliquez la méthode des 5 Pourquoi
  2. Proposez 3 solutions : Court terme / Moyen terme / Long terme
  3. Présentez votre analyse

FOCUS : QRQC

Quick Response Quality Control

Principe : Traiter le problème qualité dans les 24 heures, sur le terrain

Les 3 règles d'or :

  1. Gemba : Aller SUR PLACE
  2. Rapidité : Réaction immédiate
  3. Visuel : Photo du problème + données affichées

Bénéfices QRQC :

  • Réduction défauts : -60 à 80%
  • Coût non-qualité : -50%
  • Implication terrain : ++++

Les 3 messages à retenir :

  1. Kaizen : Vous êtes acteur de l'amélioration
  2. 5 Pourquoi : Cherchez la cause racine, pas le coupable
  3. QRQC : Traitez vite, sur le terrain
