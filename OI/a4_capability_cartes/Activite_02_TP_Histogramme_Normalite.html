📊 TP Histogramme & Normalité

Construisez un histogramme à partir de mesures réelles, vérifiez la normalité de la distribution, et interprétez les résultats.

⏱️ Durée : 90 minutes | 🛠️ Outils : Excel ou Ellistat | 📁 Fichier : diameter.csv

🏭 Contexte industriel

Un atelier d'usinage produit des axes cylindriques. La cote critique est le diamètre, dont la spécification est :

Cible : 11,88 mm  |  Tolérance : 11,84 ± 0,08 mm  →  LSI = 11,80 mm  |  LSS = 11,96 mm

30 pièces ont été mesurées consécutivement. Les données sont dans le fichier diameter.csv.

📋 Partie 1 — Statistiques descriptives (20 min)

  1. 1 Ouvrir le fichier diameter.csv dans Excel ou Ellistat
  2. 2 Calculez les statistiques suivantes :
Statistique Formule Excel Votre résultat
Nombre de mesures (n) =NB(A2:A31)
Moyenne (x̄) =MOYENNE(A2:A31)
Écart-type (s) =ECARTYPE.STANDARD(A2:A31)
Minimum =MIN(A2:A31)
Maximum =MAX(A2:A31)
Étendue (R) =MAX(...)-MIN(...)
Médiane =MEDIANE(A2:A31)

📊 Partie 2 — Construction de l'histogramme (30 min)

Méthode manuelle (comprendre le principe)

  1. 1 Nombre de classes : Utilisez la règle de Sturges : k = 1 + 3,322 × log₁₀(n). Pour n = 30 → k ≈ 6 classes
  2. 2 Amplitude des classes : h = Étendue / k
  3. 3 Bornes des classes : Commencez au minimum et ajoutez h à chaque fois
  4. 4 Comptez le nombre de mesures dans chaque classe (effectifs)

Construction sur outil

📗 Excel
📘 Ellistat
  1. Créer les bornes dans une colonne (ex : 11,84 ; 11,85 ; 11,86 … 11,93)
  2. =FREQUENCE(A2:A31; bornes) → sélectionner une colonne, valider avec Ctrl+Maj+Entrée
  3. Insérer un graphique → Histogramme (ou graphique à barres)
  4. Ajouter les limites de spécification (LSI = 11,80 et LSS = 11,96) en lignes verticales
💡 Astuce Excel : Vous pouvez aussi utiliser l'outil "Utilitaire d'analyse" → Histogramme (onglet Données → Analyse de données)
  1. Importer le fichier CSV (Fichier → Importer)
  2. Sélectionner la colonne "diameter"
  3. Aller dans Statistiques → Histogramme
  4. Renseigner les limites : LSI = 11,80 et LSS = 11,96
  5. L'histogramme est généré automatiquement avec la courbe normale superposée

🔔 Partie 3 — Vérification de la normalité (25 min)

Pour appliquer le SPC, la distribution doit être approximativement normale (en cloche). Voici 3 méthodes pour le vérifier :

Méthode 1 : Visuelle

Comparez votre histogramme à la courbe en cloche théorique. Est-il :

  • ✅ Symétrique autour de la moyenne ?
  • ✅ En forme de cloche (plus concentré au centre) ?
  • ✅ Sans « trous » ni pics multiples ?

Méthode 2 : Droite de Henry (papier de probabilité normale)

📗 Excel
📘 Ellistat
  1. Trier les données par ordre croissant
  2. Pour chaque mesure i, calculer le rang : F(i) = (i - 0,5) / n
  3. Calculer le quantile normal : =LOI.NORMALE.STANDARD.INVERSE(F(i))
  4. Tracer les mesures (axe X) vs. quantiles normaux (axe Y)
  5. Si les points forment une droite → distribution normale
  1. Statistiques → Test de normalité
  2. Sélectionner la variable "diameter"
  3. Ellistat affiche automatiquement la droite de Henry et la p-value
  4. p-value > 0,05 → on accepte la normalité

Méthode 3 : Règle rapide des 68-95-99,7

Si la distribution est normale :

  • 68% des mesures sont dans l'intervalle [x̄ - s ; x̄ + s]
  • 95% des mesures sont dans l'intervalle [x̄ - 2s ; x̄ + 2s]
  • 99,7% des mesures sont dans l'intervalle [x̄ - 3s ; x̄ + 3s]

📝 Partie 4 — Synthèse et points clés (15 min)

Ce qu'il faut retenir :
  • L'histogramme est le premier outil à utiliser pour visualiser une production
  • La loi normale (courbe en cloche) est le modèle de base du SPC
  • Il faut vérifier la normalité avant d'appliquer les indices Cp/Cpk
  • Les 3 informations clés : centrage (moyenne vs cible), dispersion (écart-type), forme (symétrie)
  • La règle 68-95-99,7 permet de vérifier rapidement la normalité
