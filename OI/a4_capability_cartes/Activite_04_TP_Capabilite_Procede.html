TP Capabilité Procédé (Cp/Cpk/Pp/Ppk)

Analysez des données de production sur le long terme, calculez les indices de capabilité procédé, et prenez des décisions qualité.

75 min | Excel ou Ellistat | Fichier : SPC-10-dimension.csv

Rappel : Court terme vs Long terme

Court terme (Cp/Cpk) Long terme (Pp/Ppk)
Ce qu'on mesure Variabilité intrinsèque Variabilité totale réelle
Écart-type utilisé σ̂ estimé (via R̄/d₂) σ global (écart-type classique)
Période couverte Quelques heures/jours Semaines/mois
Sources de variation Machine seule Machine + opérateur + matière + environnement
Question posée "Le procédé peut-il être capable ?" "Le procédé est-il réellement capable ?"

Formules

Potentiel court terme
$$C_p = \frac{IT}{6\hat{\sigma}}$$
Centrage court terme
$$C_{pk} = \min(C_{pu},\; C_{pl})$$
Potentiel long terme
$$P_p = \frac{IT}{6\sigma}$$
Centrage long terme
$$P_{pk} = \min(P_{pu},\; P_{pl})$$
Où :
\(IT = LSS - LSI\) (Intervalle de Tolérance)
\(C_{pu} = \frac{LSS - \bar{x}}{3\sigma}\)  |  \(C_{pl} = \frac{\bar{x} - LSI}{3\sigma}\)
\(\hat{\sigma} = \bar{R} / d_2\) (écart-type estimé depuis les étendues des sous-groupes)
\(\sigma\) = écart-type global de toutes les mesures

Partie 1 — Analyse des données dimensionnelles (40 min)

Le fichier SPC-10-dimension.csv contient 27 sous-groupes de 5 mesures d'une dimension critique (en µm). Spécification : LSI = 2000 µm  |  LSS = 2800 µm

Étape 1 : Calculer les statistiques par sous-groupe

Excel
Ellistat

Pour chaque sous-groupe (lignes de 5 mesures) :

Calcul Formule (ex: sous-groupe 1, cellules B2:B6)
Moyenne du groupe (X̄ᵢ) =MOYENNE(B2:B6)
Étendue du groupe (Rᵢ) =MAX(B2:B6)-MIN(B2:B6)

Puis les moyennes globales :

Calcul Formule
Moyenne générale (X̿) =MOYENNE(toutes les X̄ᵢ)
Étendue moyenne (R̄) =MOYENNE(toutes les Rᵢ)
σ̂ (court terme) =R̄ / 2,326 (d₂ pour n=5)
σ global (long terme) =ECARTYPE.STANDARD(toutes les mesures)

Étape 2 : Calculer les 4 indices

Indice Formule Excel Votre résultat
Cp =(2800-2000)/(6*σ̂)
Cpk =MIN((2800-X̿)/(3*σ̂); (X̿-2000)/(3*σ̂))
Pp =(2800-2000)/(6*σ_global)
Ppk =MIN((2800-X̿)/(3*σ_global); (X̿-2000)/(3*σ_global))

Partie 2 — Interprétation et diagnostic (20 min)

Arbre de décision

Cp ≥ 1,33 ?
OUI → La dispersion est acceptable. Le procédé a le POTENTIEL d'être capable.
NON → La dispersion est trop grande. Il faut réduire la variabilité (améliorer la machine, les outils, la matière…)
Cpk ≥ 1,33 ?
OUI → Le procédé est capable ET bien centré à court terme.
NON (mais Cp OK) → Le procédé est décentré. Il faut recentrer (régler la machine sur la cible).
Pp ≈ Cp ?
OUI → Le procédé est stable dans le temps. Pas de sources de variation supplémentaires.
NON (Pp << Cp) → Le procédé dérive dans le temps ! Des causes spéciales agissent sur le long terme.
Ppk ≥ 1,33 ?
OUI → Le procédé est réellement capable en production. Validation OK.
NON → Le client reçoit potentiellement des pièces non conformes. Action requise.

Partie 3 — Exercice complémentaire : Remplissage (15 min)

Ouvrez le fichier SPC-9-remplissage.csv. Il contient 16 sous-groupes de 10 mesures d'écart de remplissage (unité : mL). Spécification : LSI = −3 mL  |  LSS = +3 mL

Question 3

Calculez Cp, Cpk, Pp, Ppk pour ces données de remplissage. Le procédé de remplissage est-il plus ou moins capable que le procédé dimensionnel ?

Points clés à retenir

  • Cp / Pp = potentiel → "La tolérance est-elle assez large par rapport à ma dispersion ?"
  • Cpk / Ppk = réel → "En plus du potentiel, suis-je bien centré ?"
  • Cp = Cpk → parfaitement centré
  • Cp > Cpk → problème de centrage (action simple : rerégler)
  • Cp >> Pp → instabilité long terme (causes spéciales à trouver)
  • Seuil industriel courant : ≥ 1,33 (série) ou ≥ 1,67 (qualification)
