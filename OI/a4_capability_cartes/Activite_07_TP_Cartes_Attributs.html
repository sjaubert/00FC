TP Cartes aux Attributs (p, np, c, u)

Quand les données ne sont pas des mesures mais des comptages (conforme/non conforme, nombre de défauts), on utilise des cartes aux attributs.

60 min | Fichiers : SPC-1-inspection.csv & SPC-3-liquide.csv

Quand utiliser quelle carte ?

Carte p (proportion)

Proportion de pièces non conformes dans un échantillon

Quand : taille d'échantillon variable | Ex : % de rebuts par lot

Carte np (nombre)

Nombre de pièces non conformes dans un échantillon

Quand : taille d'échantillon constante | Ex : nb défectueux sur 100 pièces

Carte c (comptage)

Nombre de défauts par unité d'inspection

Quand : zone d'inspection constante | Ex : nombre de défauts par lot

Carte u (taux)

Taux de défauts par unité d'area variable

Quand : zone d'inspection variable | Ex : défauts/m² de tissu
Distinction clé :
• p / np = pièce conforme OU non conforme (binaire) → loi binomiale
• c / u = nombre de défauts par unité (une pièce peut avoir 0, 1, 2… défauts) → loi de Poisson

Exercice 1 — Carte p : Inspection visuelle (35 min)

Contexte : Un contrôle visuel est effectué quotidiennement. Le fichier SPC-1-inspection.csv contient le nombre de pièces non conformes (X) observées chaque jour sur un lot de 200 pièces inspectées.

Formules de la carte p

p̄ = Σ(non conformes) / Σ(inspectées)
Proportion moyenne de non conformes
LCS = p̄ + 3 × √(p̄(1−p̄)/n)
LCI = p̄ − 3 × √(p̄(1−p̄)/n)
n = taille de l'échantillon (ici n = 200)

Instructions

Excel
Ellistat
  1. Ouvrir SPC-1-inspection.csv
  2. Calculer pᵢ = X / 200 pour chaque jour
  3. Calculer p̄ : =MOYENNE(toutes les pᵢ) ou =SOMME(X) / (NB(X)*200)
  4. Calculer LCS : =p̄ + 3*RACINE(p̄*(1-p̄)/200)
  5. Calculer LCI : =MAX(0; p̄ - 3*RACINE(p̄*(1-p̄)/200))
  6. Tracer un graphique : pᵢ (points), p̄ (ligne verte), LCS/LCI (lignes rouges)
  1. Importer le fichier CSV
  2. Cartes de contrôle → Attributs → Carte p
  3. Renseigner n = 200 (taille d'échantillon)
  4. La carte est générée automatiquement

Question 1

Calculez p̄, LCS et LCI. Combien de points sont hors limites ? Le procédé d'inspection est-il sous contrôle ?

Exercice 2 — Carte c : Défauts par lot de liquide (20 min)

Contexte : Le fichier SPC-3-liquide.csv contient le nombre de particules contaminantes détectées par lot dans un processus de fabrication de liquide pharmaceutique (17 lots).

Formules de la carte c

c̄ = Σ(défauts) / nombre de lots
Nombre moyen de défauts par unité
LCS = c̄ + 3 × √c̄
LCI = max(0, c̄ − 3 × √c̄)
Limites basées sur la loi de Poisson

Instructions

  1. Calculer c̄ = moyenne des X
  2. Calculer LCS = =c̄ + 3*RACINE(c̄)
  3. Calculer LCI = =MAX(0; c̄ - 3*RACINE(c̄))
  4. Tracer la carte c : un point par lot

Question 2

Le lot n°17 (44 particules) est-il hors limite ? Le lot n°16 (34 particules) ? Que recommandez-vous ?

Synthèse : Variables vs Attributs

Cartes aux mesures (X̄-R) Cartes aux attributs (p, c…)
Type de données Mesures continues (mm, kg, °C…) Comptages (conforme/non, nb défauts)
Sensibilité Très sensible (détecte de petits changements) Moins sensible (nécessite plus de données)
Taille d'échantillon Petite (3 à 10 pièces) Grande (50 à 200+ pièces)
Coût Plus élevé (mesure précise) Plus faible (contrôle visuel)
Quand l'utiliser Cotes critiques, paramètres process Aspect visuel, contrôle réception
