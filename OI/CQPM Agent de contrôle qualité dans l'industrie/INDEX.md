## 🛠️ Logiciels Utilisés

### Excel (Microsoft)
**TP concernés** : TP1, TP2, TP3, TP4, TP5, TP6

**Fonctions enseignées** :
- Statistiques : `MOYENNE()`, `ECARTYPE.STANDARD()`, `VAR.S()`, `MIN()`, `MAX()`, `MEDIANE()`
- Conditionnelles : `NB.SI()`, `NB.SI.ENS()`
- Quartiles : `QUARTILE.INCLUS()`
- Loi normale : `LOI.NORMALE.STANDARD.N()`
- Graphiques : Histogrammes, courbes, box plots
- Cartes de contrôle : Avec limites calculées (A2, D3, D4)

**Ressources** : [Ressources_Complementaires.md](./Ressources_Complementaires.md) → Section "Logiciels"

**Ressources** : Site officiel, tutoriels dans ressources complémentaires

## 📋 Check-list Formateur

### Avant la Formation

- [ ] Lire README.md et les 2 déroulés pédagogiques
- [ ] Consulter le Glossaire (vocabulaire cohérent)
- [ ] Préparer l'environnement logiciel :
  - [ ] Excel (version 2016+ recommandée)
  - [ ] Ellistat (licences ou version démo)
  - [ ] R + RStudio (installation collective)
- [ ] Créer/adapter les fichiers de données :
  - [ ] TP1 : Template et corrigé Excel
  - [ ] TP2 : Template AMDEC
  - [ ] TP4 : Fichier 100 mesures
  - [ ] Etc. (voir walkthrough.md pour liste complète)
- [ ] Tester tous les TP en amont
- [ ] Préparer supports de présentation si besoin
- [ ] Vérifier salle : vidéoprojecteur, tableau, postes informatiques

### Pendant la Formation

- [ ] Respecter les timings (pauses, transitions)
- [ ] Alterner théorie/pratique (ne pas faire 3h de théorie d'affilée !)
- [ ] Vérifier compréhension régulièrement
- [ ] Adapter exemples au secteur des stagiaires si possible
- [ ] Encourager questions et échanges

### Après la Formation

- [ ] Récupérer feedback stagiaires
- [ ] Archiver productions stagiaires (portfolio)
- [ ] Mettre à jour documents si nécessaire
- [ ] Partager améliorations avec autres formateurs
