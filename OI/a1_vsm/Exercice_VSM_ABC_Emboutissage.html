Value Stream Mapping (VSM)

Exercice Pratique - ABC Emboutissage Ltée

Introduction : Qu'est-ce que la VSM ?

La Cartographie de la Chaîne de Valeur (Value Stream Mapping - VSM) est un outil essentiel du Lean Manufacturing qui vous permet de :

  • Visualiser l'ensemble du flux de production et d'information
  • Identifier les gaspillages (muda) invisibles au quotidien
  • Créer un langage commun pour toute l'équipe
  • Planifier les améliorations de manière structurée

Le Secret de la VSM

Une carte de chaîne de valeur révèle souvent que plus de 95% du temps de traversée d'un produit est du gaspillage (attente, stock, transport) et seulement une infime partie est du temps à valeur ajoutée réelle.

Méthodologie : Les 5 Règles d'Or

  1. Choisir UNE famille de produits
    Ne cartographiez qu'une seule famille de produits à la fois (produits partageant des étapes similaires).
  2. Parcourir le terrain soi-même
    L'observation directe est irremplaçable. Marchez le long du flux physique des matières.
  3. Commencer par la fin
    Débutez à l'expédition et remontez vers les matières premières. Le client est le point de départ de toute la chaîne.
  4. Mesurer avec un chronomètre
    Utilisez des données réelles, pas les standards théoriques. Chronométrez vous-même.
  5. Dessiner à la main
    Pour la première ébauche, utilisez papier et crayon. Pas d'ordinateur ! Cela force la compréhension.

Note de l'Expert

Le but n'est PAS de créer de beaux schémas. L'objectif est de comprendre profondément ce qui se passe réellement sur le terrain. Une carte raturée mais juste vaut mieux qu'un diagramme parfait mais faux.

Votre Mission

Objectif de l'Exercice

Avec les données fournies ci-dessus, vous devez :

  1. Dessiner la carte VSM de l'état actuel sur une feuille de papier
  2. Calculer le Takt Time (rythme de demande du client)
  3. Identifier le processus goulot (processus le plus lent)
  4. Calculer le délai de production total (Lead Time)
  5. Calculer le temps de traitement total (temps à valeur ajoutée)

Étapes de Construction

  1. Étape 1 : Dessinez le client (coin supérieur droit) avec sa case de données
  2. Étape 2 : Dessinez les 5 processus de production (de gauche à droite, partie basse)
  3. Étape 3 : Ajoutez les cases de données sous chaque processus
  4. Étape 4 : Ajoutez les triangles de stock entre les processus avec les quantités
  5. Étape 5 : Dessinez le fournisseur (coin supérieur gauche)
  6. Étape 6 : Ajoutez le flux d'information (partie supérieure)
  7. Étape 7 : Tracez la ligne de temps (partie basse) et calculez les métriques

Analyse et Solution

1. Calcul du Takt Time

Le Takt Time représente le rythme auquel nous devons produire pour satisfaire la demande client.

Takt Time = Temps disponible / Demande client Demande quotidienne = 18 400 pièces / 20 jours = 920 pièces/jour Temps disponible par jour = 55 200 secondes (920 minutes × 60) Takt Time = 55 200 s ÷ 920 pièces = 60 secondes/pièce

Interprétation

Pour satisfaire la demande, ABC Emboutissage doit produire une pièce toutes les 60 secondes.

2. Identification du Goulot d'Étranglement

Comparons les temps de cycle de chaque processus avec le Takt Time :

Processus TC (s) vs Takt Time (60s) Statut
Emboutissage 1 s OK Capacité largement suffisante
Soudage I 39 s OK Peut suivre le rythme
Soudage II 46 s OK Peut suivre le rythme
Montage I 62 s PROBLÈME GOULOT
Montage II 40 s OK Peut suivre le rythme

Goulot Identifié : Montage I

Le Montage I (62 secondes) est plus lent que le Takt Time (60 secondes). C'est le goulot d'étranglement qui limite la capacité de production de toute la chaîne !

Conséquence : ABC ne peut pas satisfaire la demande actuelle sans amélioration de ce poste.

3. Calcul du Délai de Production (Lead Time)

Le délai de production représente le temps qu'une pièce passe dans l'usine, de la réception des matières premières à l'expédition.

Calcul des stocks en jours : • Stock matière première : 5 jours (rouleaux d'acier) • Stock après Emboutissage : (4 600 + 2 400) / 920 = 7,6 jours • Stock après Soudage I : (1 100 + 600) / 920 = 1,8 jours • Stock après Soudage II : (1 600 + 850) / 920 = 2,7 jours • Stock après Montage I : (1 200 + 640) / 920 = 2,0 jours • Stock produits finis : (2 700 + 1 440) / 920 = 4,5 jours Délai Total = 5 + 7,6 + 1,8 + 2,7 + 2,0 + 4,5 = 23,6 jours

4. Temps de Traitement (Valeur Ajoutée)

Le temps de traitement est la somme des temps de cycle, c'est-à-dire le temps pendant lequel le produit est réellement transformé.

Temps de Traitement = Somme des TC 1 s + 39 s + 46 s + 62 s + 40 s = 188 secondes

5. La Révélation Choc

L'Équation qui Change Tout

23,6 jours de traversée
pour seulement
188 secondes de travail réel

Ratio : 188 s / (23,6 × 16h × 3600s) = 0,014%

Seulement 0,014% du temps apporte de la valeur !
99,986% du temps est du gaspillage (muda) !

6. Points d'Amélioration Identifiés

  1. Goulot d'étranglement (Montage I - URGENT) :
    • TC = 62s > Takt Time = 60s
    • Solutions : Ajouter un opérateur, améliorer la méthode, automatiser partiellement
  2. Stocks excessifs :
    • 7,6 jours après emboutissage (le plus gros stock)
    • 4,5 jours de produits finis
    • Solution : Implémenter un flux tiré (kanban), réduire les lots
  3. Flux poussé :
    • Chaque processus produit selon un calendrier hebdomadaire
    • Solution : Passer à un système de production tirée (pull)
  4. Fiabilité faible :
    • Emboutissage : 85% (15% de pannes)
    • Soudage II : 80% (20% de pannes)
    • Solution : Maintenance productive totale (TPM)

Prochaine Étape : L'État Futur

Maintenant que vous avez identifié les problèmes, l'étape suivante consiste à dessiner la carte de l'état futur intégrant les améliorations Lean :

  • Flux tiré avec supermarchés et kanbans
  • Réduction des lots de production
  • Pacemaker au niveau du goulot
  • SMED pour réduire les temps de changement
  • Cellules de production en flux continu

Points Clés à Retenir

La VSM rend visible l'invisible

La majorité du temps de production est du gaspillage. La VSM le révèle clairement.

Le Takt Time est votre boussole

C'est le rythme du client. Tous vos processus doivent suivre ce rythme.

Les stocks cachent les problèmes

Des stocks élevés masquent les pannes, les défauts et les déséquilibres.

Le flux tiré vs flux poussé

Le flux poussé crée de la surproduction. Le flux tiré synchronise avec la demande réelle.

Observer sur le terrain

Les données théoriques sont trompeuses. Seule l'observation directe révèle la réalité.

La VSM est un point de départ

Elle ne résout pas les problèmes, mais elle les rend impossibles à ignorer.
