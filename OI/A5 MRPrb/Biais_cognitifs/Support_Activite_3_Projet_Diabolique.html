Activite 3 : Projet Diabolique

Pole Formation UIMM-CVDL

Objectif de l'activite

Creer le produit, service ou experience LA PLUS MANIPULATRICE possible en utilisant les biais cognitifs

ATTENTION - Point ethique important

Cet exercice est purement pedagogique !

L'objectif est de COMPRENDRE les mecanismes de manipulation pour mieux s'en PROTEGER, PAS de les appliquer reellement !

Une fois que vous savez comment fonctionne la manipulation :

  • Protegez-vous en tant que consommateur
  • Protegez vos utilisateurs en tant que professionnel
  • Utilisez ces connaissances de maniere ethique !

Deroulement de l'activite

Duree totale : 1h30

Phase 1 : Introduction (10 minutes)

L'animateur presente des exemples de "Dark UX" (design manipulateur) pour vous aider a comprendre comment les biais peuvent etre utilises pour manipuler.

Phase 2 : Creation (50 minutes)

50 minutes
Consigne : Creez un produit, service, publicite ou experience qui utilise AU MINIMUM 7 biais cognitifs differents pour manipuler les utilisateurs.

Contraintes obligatoires :

  1. Utiliser au moins 7 biais cognitifs differents
  2. Utiliser au moins 1 biais de chaque categorie (les 5 familles)
  3. Documenter precisement quel biais est utilise et COMMENT
  4. Creer un support visuel (dessin, storyboard, mockup, pitch)

Exemples de creations possibles :

  • Une application mobile addictive
  • Une publicite ultra-persuasive
  • Un site e-commerce manipulateur
  • Une experience en magasin
  • Une campagne marketing
  • Un processus de vente

Phase 3 : Presentations "diaboliques" (30 minutes)

30 minutes

Chaque equipe presente son projet (environ 5 minutes par equipe)

Format de presentation :

  1. Description de votre creation
  2. Demonstration de chaque biais utilise :
    • Quel biais ?
    • Comment il est applique dans votre projet ?
    • Quel effet attendu sur l'utilisateur ?
  3. Impact global sur l'utilisateur

Bareme de points

Action Points
Biais correctement applique et justifie 2 points
Bonus : Equipe la plus "diabolique" (vote des participants) +3 points
Bonus : Equipe la plus creative (vote de l'animateur) +3 points

Rappel des 5 categories

Assurez-vous d'utiliser au moins 1 biais de chaque categorie :

  1. Memoire et Souvenirs (Violet)
  2. Raisonnement et Resolution de problemes (Bleu)
  3. Prise de decision et Comportements (Vert)
  4. Travail d'equipe et Reunions (Orange)
  5. Interviews et Tests utilisateur (Rose)

Conseils pour reussir

  • Soyez creatifs : Laissez libre cours a votre imagination
  • Pensez "utilisateur" : Comment chaque biais va influencer le comportement
  • Documentez bien : La grille est importante pour la presentation
  • Verifiez la couverture : Avez-vous bien 1 biais de chaque categorie ?
  • Preparez votre pitch : 5 minutes pour convaincre que votre projet est le plus manipulateur
