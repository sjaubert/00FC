🧠 Jeu sur les Biais Cognitifs

Formation d'une journée complète

Description : Jeu pédagogique interactif basé sur les 52 cartes de biais cognitifs pour animer une formation d'une journée.

Objectifs : Découvrir les 5 catégories de biais cognitifs, identifier les biais dans des situations professionnelles, et apprendre des stratégies pour limiter leur impact.

Public : Débutants en biais cognitifs

Durée : 1 journée (7 heures)

ℹ️ Contenu du jeu

Phase 1 : Découverte des Catégories (1h15)

Les participants découvrent les 5 catégories de biais cognitifs via des activités de classification et un quiz interactif.

Phase 2 : Chasseurs de biais (1h30)

Les équipes analysent 15 scénarios professionnels pour identifier les biais cognitifs présents.

Phase 3 : Projet Diabolique (1h30)

Exercice créatif : concevoir une expérience manipulatrice utilisant les biais (approche pédagogique pour comprendre les mécanismes).

Phase 4 : Détox Cognitive (1h15)

Découverte de 7 stratégies anti-biais et création d'un plan d'action personnel.

Phase 5 : Grand Quiz Final (30 min)

Quiz de validation des acquis et proclamation de l'équipe gagnante.
