## 1. OBJECTIFS PÉDAGOGIQUES

À l'issue de cette simulation, les participants seront capables de :

- **Appliquer** les 8 disciplines de résolution de problèmes
- **Utiliser** les outils d'analyse (QQOQCP, Ishikawa, 5 Pourquoi)

- **Documenter** une résolution de problème de manière structurée
- **Collaborer** en équipe pluridisciplinaire
- **Présenter** une synthèse 8D à la direction

## 2. PRÉSENTATION DE LA MÉTHODE 8D

### 2.1 Origine

La méthode 8D (Eight Disciplines) a été développée par Ford Motor Company dans les années 1980. Elle est aujourd'hui le standard dans l'automobile et l'aéronautique pour traiter les non-conformités critiques.

### 2.2 Les 8 Disciplines

| D | Intitulé | Objectif | Outils |
|---|----------|----------|--------|
| D0 | Préparation | Évaluer l'urgence et l'impact | Matrice d'urgence |
| D1 | Formation équipe | Réunir les compétences | Team Building, RASI |
| D2 | Description problème | Définir précisément le problème | QQOQCP, IS/IS NOT |
| D3 | Actions conservatoires | Protéger le client sous 24h | Confinement, Tri |
| D4 | Analyse causes racines | Trouver le POURQUOI | 5 Pourquoi, Ishikawa |
| D5 | Actions correctives | Choisir les solutions | Test pilote |
| D6 | Mise en œuvre | Déployer définitivement | Standardisation |
| D7 | Prévention récurrence | Éviter que ça se reproduise | AMDEC, Poka-Yoke |
| D8 | Reconnaissance | Féliciter et archiver | Célébration, Retex |

### 2.3 Concept clé : Double cause racine

Le D4 doit identifier DEUX types de causes :

1. **Cause d'occurrence** : Pourquoi le défaut est-il apparu ?
2. **Cause de non-détection** : Pourquoi le système n'a-t-il pas arrêté le défaut ?

## 3. SCÉNARIO DU JEU

### 3.1 Contexte de l'entreprise

**METALUX SAS** est un équipementier automobile de rang 1 qui fabrique des supports de fixation pour systèmes de freinage. L'entreprise livre principalement le groupe PSA et Renault.

- Effectif : 150 personnes
- Certifications : IATF 16949, ISO 14001
- Chiffre d'affaires : 25 millions EUR

### 3.2 La réclamation client

**Date** : Lundi 15 janvier 2026, 8h00

**Client** : Stellantis (ex-PSA), usine de Sochaux

**Référence pièce** : SUP-FRE-2847

**Message du client** :

> "Nous avons détecté sur notre ligne d'assemblage 12 supports de fixation présentant un défaut de soudure. Les soudures sont poreuses et ne respectent pas les spécifications. Nous avons dû arrêter notre ligne pendant 2 heures. Nous vous demandons un rapport 8D sous 48 heures avec actions de confinement immédiates."

### 3.3 Informations initiales

- Quantité livrée : 5000 pièces (lot n° L2401-2847)
- Date de fabrication : 8-9 janvier 2026
- Date de livraison : 12 janvier 2026
- Nombre de pièces défectueuses détectées par le client : 12

### 3.4 Impact client

- Arrêt de ligne : 2 heures
- Coût horaire ligne : 10 000 EUR/heure
- Pénalité contractuelle potentielle : 50 000 EUR
- Risque de déréférencement si récurrence

## 6. SOLUTION ATTENDUE

### 6.1 D2 - Description du problème

**QQOQCP** :

- **Quoi** : Défaut de soudure (porosité)
- **Qui** : Détecté par client Stellantis
- **Où** : Ligne assemblage Sochaux, référence SUP-FRE-2847
- **Quand** : 15 janvier, pièces fabriquées les 8-9 janvier
- **Comment** : Arrêt ligne client, 12 pièces détectées
- **Pourquoi** : Non-respect spec porosité (8-12% au lieu de 2% max)

**IS / IS NOT** :

- IS : Lot L2401-2847, 8-9 janvier
- IS NOT : Lots précédents, autres références

### 6.2 D3 - Actions conservatoires

1. Tri immédiat du stock restant chez METALUX
2. Alerte au client sur le lot concerné
3. Tri chez le client des pièces non montées
4. Contrôle 100% ressuage du lot
5. Renfort contrôle sur production en cours

### 6.3 D4 - Causes racines

**Cause d'occurrence** (5 Pourquoi) :

1. Pourquoi la soudure est-elle poreuse ? -> Présence d'humidité
2. Pourquoi y avait-il de l'humidité ? -> Fil de soudure oxydé/humide
3. Pourquoi le fil était-il humide ? -> Stockage près de la porte (froid + condensation)
4. Pourquoi a-t-il été stocké là ? -> Pas de zone de stockage définie
5. Pourquoi pas de zone définie ? -> Procédure de stockage inexistante pour consommables

**Cause de non-détection** :

1. Pourquoi le défaut n'a-t-il pas été détecté ? -> Contrôle visuel insuffisant pour porosité interne
2. Pourquoi pas de contrôle adapté ? -> Fréquence ressuage 1/500 trop faible pour ce risque
3. Pourquoi cette fréquence ? -> Plan de contrôle non revu depuis 3 ans

**Cause secondaire** : L'application de WD-40 par l'intérimaire a aggravé le problème (huile = contamination supplémentaire)

### 6.4 D5-D6 - Actions correctives

| Action | Responsable | Délai |
|--------|-------------|-------|
| Définir zone stockage fil chauffée | Logistique | J+7 |
| Former opérateurs au stockage | RH | J+14 |
| Augmenter fréquence ressuage 1/100 | Qualité | Immédiat |
| Interdire produits non validés sur machine | Production | Immédiat |
| Mise à jour plan de contrôle | Qualité | J+30 |

### 6.5 D7 - Prévention récurrence

1. AMDEC process mise à jour (stockage consommables)
2. Procédure stockage fil de soudure formalisée
3. Formation renforcée des intérimaires
4. Poka-Yoke : capteur humidité sur dévidoir

### 6.6 D8 - Reconnaissance

- Félicitations à l'équipe
- Retour d'expérience partagé
- Archivage dans base de données qualité
- Communication au client
