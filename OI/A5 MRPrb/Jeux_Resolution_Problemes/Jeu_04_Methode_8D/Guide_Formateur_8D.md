## 2. PRESENTATION DE LA METHODE 8D

### 2.1 Origine

La methode 8D (Eight Disciplines) a ete developpee par Ford Motor Company dans les annees 1980. Elle est aujourd'hui le standard dans l'automobile et l'aeronautique pour traiter les non-conformites critiques.

### 2.2 Les 8 Disciplines

| D | Intitule | Objectif | Outils |
|---|----------|----------|--------|
| D0 | Preparation | Evaluer l'urgence et l'impact | Matrice d'urgence |
| D1 | Formation equipe | Reunir les competences | Team Building, RASI |
| D2 | Description probleme | Definir precisement le probleme | QQOQCP, IS/IS NOT |
| D3 | Actions conservatoires | Proteger le client sous 24h | Confinement, Tri |
| D4 | Analyse causes racines | Trouver le POURQUOI | 5 Pourquoi, Ishikawa |
| D5 | Actions correctives | Choisir les solutions | Test pilote |
| D6 | Mise en oeuvre | Deployer definitivement | Standardisation |
| D7 | Prevention recurrence | Eviter que ca se reproduise | AMDEC, Poka-Yoke |
| D8 | Reconnaissance | Feliciter et archiver | Celebration, Retex |

### 2.3 Concept cle : Double cause racine

Le D4 doit identifier DEUX types de causes :

1. **Cause d'occurrence** : Pourquoi le defaut est-il apparu ?
2. **Cause de non-detection** : Pourquoi le systeme n'a-t-il pas arrete le defaut ?

## 6. SOLUTION ATTENDUE

### 6.1 D2 - Description du probleme

**QQOQCP** :

- **Quoi** : Defaut de soudure (porosite)
- **Qui** : Detecte par client Stellantis
- **Ou** : Ligne assemblage Sochaux, reference SUP-FRE-2847
- **Quand** : 15 janvier, pieces fabriquees les 8-9 janvier
- **Comment** : Arret ligne client, 12 pieces detectees
- **Pourquoi** : Non-respect spec porosite (8-12% au lieu de 2% max)

**IS / IS NOT** :

- IS : Lot L2401-2847, 8-9 janvier
- IS NOT : Lots precedents, autres references

### 6.2 D3 - Actions conservatoires

1. Tri immediat du stock restant chez METALUX
2. Alerte au client sur le lot concerne
3. Tri chez le client des pieces non montees
4. Controle 100% ressuage du lot
5. Renfort controle sur production en cours

### 6.3 D4 - Causes racines

**Cause d'occurrence** (5 Pourquoi) :

1. Pourquoi la soudure est-elle poreuse ? -> Presence d'humidite
2. Pourquoi y avait-il de l'humidite ? -> Fil de soudure oxyde/humide
3. Pourquoi le fil etait-il humide ? -> Stockage pres de la porte (froid + condensation)
4. Pourquoi a-t-il ete stocke la ? -> Pas de zone de stockage definie
5. Pourquoi pas de zone definie ? -> Procedure de stockage inexistante pour consommables

**Cause de non-detection** :

1. Pourquoi le defaut n'a-t-il pas ete detecte ? -> Controle visuel insuffisant pour porosite interne
2. Pourquoi pas de controle adapte ? -> Frequence ressuage 1/500 trop faible pour ce risque
3. Pourquoi cette frequence ? -> Plan de controle non revu depuis 3 ans

**Cause secondaire** : L'application de WD-40 par l'interimaire a aggrave le probleme (huile = contamination supplementaire)

### 6.4 D5-D6 - Actions correctives

| Action | Responsable | Delai |
|--------|-------------|-------|
| Definir zone stockage fil chauffee | Logistique | J+7 |
| Former operateurs au stockage | RH | J+14 |
| Augmenter frequence ressuage 1/100 | Qualite | Immediat |
| Interdire produits non valides sur machine | Production | Immediat |
| Mise a jour plan de controle | Qualite | J+30 |

### 6.5 D7 - Prevention recurrence

1. AMDEC process mise a jour (stockage consommables)
2. Procedure stockage fil de soudure formalisee
3. Formation renforcee des interimaires
4. Poka-Yoke : capteur humidite sur devidoir

### 6.6 D8 - Reconnaissance

- Felicitations a l'equipe
- Retour d'experience partage
- Archivage dans base de donnees qualite
- Communication au client
