# Guide du Formateur - Jeux de Rôle Résolution de Problèmes

## 🎯 Objectifs Pédagogiques Généraux

### Savoirs (Connaissances)

- Connaître les principales méthodes de résolution de problèmes (QRQC, 8D, 5 Pourquoi, Pareto, Poka-Yoke, Kaizen)
- Comprendre les principes Lean (Genba, Auto-Qualité, Management Visuel)
- Identifier les outils qualité appropriés selon les situations

### Savoir-faire (Compétences)

- Appliquer une méthode structurée face à un problème
- Utiliser les outils (QQOQCP, Ishikawa, Pareto, etc.)
- Travailler en équipe pluridisciplinaire
- Prendre des décisions sous pression

### Savoir-être (Attitudes)

- Adopter une posture d'analyse plutôt que de jugement
- Aller sur le terrain (Genba)
- Avoir le courage d'arrêter la production si nécessaire
- Être créatif dans la recherche de solutions simples

## 🎭 Principes d'Animation des Jeux de Rôle

### Avant le Jeu (5-10 min)

#### 1. Contextualiser

- "Nous allons vivre une situation réelle d'entreprise"
- Expliquer l'enjeu et la méthode visée
- Préciser la durée (et respecter le timing !)

#### 2. Distribution des rôles

```
Méthode 1 : Tirage au sort (cartes de rôles)
  → Avantage : Aléatoire, personne ne choisit la facilité
  → Inconvénient : Peut mettre une personne timide dans un rôle difficile

Méthode 2 : Volontariat encadré
  → "Qui se sent à l'aise pour jouer le chef d'équipe ?"
  → Avantage : Engagement plus fort
  → Inconvénient : Toujours les mêmes qui se portent volontaires

Méthode 3 : Attribution stratégique (recommandée)
  → Observer les profils des participants
  → Mettre un profil "leader naturel" en chef d'équipe
  → Mettre un profil "analytique" en qualiticien
  → Équilibrer les équipes si plusieurs groupes
```

#### 3. Distribuer les indices

- **Ne PAS tout donner d'un coup**
- Indices 1-5 : Donnés au départ
- Autres indices : Sur demande ou si condition remplie
- **Principe** : "Vous devez CHERCHER les informations"

#### 4. Lancer le chrono

- Utiliser un chronomètre visible de tous
- Annoncer les paliers : "Il vous reste 20 minutes"
- La pression du temps est ÉDUCATIVE (réalisme)

---

### Pendant le Jeu (30-60 min selon JdR)

#### Posture du Formateur : "L'Observateur Actif"

**CE QU'IL FAUT FAIRE** ✅

1. **Observer en silence** (80% du temps)
   - Noter les comportements remarquables (bons et mauvais)
   - Identifier les erreurs de raisonnement
   - Repérer qui participe, qui est en retrait

2. **Orienter par questionnement** (15% du temps)
   - "Avez-vous vérifié sur le terrain ?"
   - "Qu'est-ce que cette donnée vous indique ?"
   - "Êtes-vous sûrs de cette hypothèse ?"
   - Jamais dire "c'est faux", toujours questionner

3. **Jouer le rôle du "Saboteur/Perturbateur"** (5% du temps)
   - Selon le scénario prévu
   - Donner de fausses pistes si on ne vous pose pas les bonnes questions
   - Exemple JdR1 : Si on téléphone au lieu de venir voir → "Oui oui, tout est en ordre"
   - Si on vient physiquement → "Ah tiens, maintenant que vous le dites, le support bouge un peu"

**CE QU'IL NE FAUT PAS FAIRE** ❌

- ❌ Donner la réponse directement
- ❌ Intervenir dès qu'une erreur est commise (laissez-les se tromper !)
- ❌ Favoriser une équipe si plusieurs groupes
- ❌ Prolonger le temps (sauf exception pédagogique justifiée)
- ❌ Rester derrière un bureau (circuler !)

---

### Gestion des Cas Particuliers

#### Cas 1 : L'équipe est complètement bloquée (>15 min sans progression)

```
Solution : Donner un "Joker"
  → "Je vous donne un indice : avez-vous vérifié l'état du détrompeur ?"
  → Noter que ce joker a été nécessaire (élément de débriefing)
```

#### Cas 2 : L'équipe va trop vite et trouve trop facilement

```
Solution : Complexifier légèrement
  → "Êtes-vous vraiment sûrs ? Avez-vous vérifié TOUTES les hypothèses ?"
  → Introduire un doute (sans mentir)
```

#### Cas 3 : Un participant monopolise la parole

```
Solution : Redistribuer la parole
  → "Merci Marc. Et toi Sophie, qu'en penses-tu ?"
  → "Marc, tu as le rôle de technicien. Laissons le chef d'équipe décider."
```

#### Cas 4 : Un participant ne participe pas du tout

```
Solution : L'interpeller directement (en douceur)
  → "Ahmed, en tant qu'opérateur, qu'as-tu observé ?"
  → Lui confier une tâche spécifique : "Ahmed, peux-tu remplir le QQOQCP pendant que les autres cherchent ?"
```

#### Cas 5 : Conflit/tension dans le groupe

```
Solution : Rappeler le cadre
  → "On est dans une simulation, l'objectif est d'apprendre ensemble"
  → Si tension persistante : faire une pause de 5 min
```

### Après le Jeu : Le Débriefing (15-45 min selon JdR)

> **Le débriefing est PLUS IMPORTANT que le jeu lui-même**  
> C'est là que l'apprentissage se cristallise.

#### Structure du Débriefing (Méthode QQF)

##### 1️⃣ QUOI ? (Que s'est-il passé ?) - 5 min

**Questions** :

- "Racontez-moi ce que vous avez fait"
- "Quelle a été votre première réaction ?"
- "Quelle décision avez-vous prise ?"
- "Avez-vous trouvé la cause racine ?"

**Objectif** : Faire un récit factuel, sans jugement encore

##### 2️⃣ QUALIFIER (Qu'avez-vous ressenti ?) - 5 min

**Questions** :

- "Comment vous êtes-vous sentis sous pression ?"
- "Qu'est-ce qui a été difficile ?"
- "Y a-t-il eu des moments de doute ?"
- "Avez-vous été surpris par quelque chose ?"

**Objectif** : Faire émerger les émotions, le vécu

##### 3️⃣ FEEDBACK (Qu'avez-vous appris ?) - 10-30 min

**A. Points positifs d'abord** ✅

```
"Vous avez très bien fait de..."
- Aller sur le terrain immédiatement
- Remplir le QQOQCP de manière structurée
- Ne pas accuser l'opérateur
- Prendre le temps d'analyser avant de décider
```

**B. Points d'amélioration** 🔄

```
"Ce qui aurait pu être amélioré..."
- Vous avez sauté l'étape X de la méthode 8D
- Vous n'avez pas vérifié toutes les hypothèses
- Vous avez voulu aller trop vite vers la solution
- La pression du délai vous a fait oublier la rigueur
```

**C. Lien avec la théorie** 📚

```
"Vous avez appliqué le principe de..."
- San Gen Shugi (les 3 réels)
- Auto-Qualité (arrêt de la ligne)
- Pareto (priorisation)

"Vous avez oublié le principe de..."
- Toujours vérifier sur le terrain
- Ne jamais supposer, toujours vérifier
```

**D. Transposition au réel** 🏭

```
"Dans votre entreprise, comment feriez-vous ?"
- Quels outils pourriez-vous réutiliser ?
- Quels obstacles prévisibles ?
- Quel serait le premier problème à traiter avec cette méthode ?
```

## 💡 Conseils et Bonnes Pratiques

### Pour Réussir vos Jeux de Rôle

#### 1. La Préparation est Clé

- [ ] Lire TOUS les documents 2 fois avant la session
- [ ] Tester le jeu avec des collègues formateurs si possible
- [ ] Préparer les indices physiquement (enveloppes numérotées)
- [ ] Avoir un plan B si problème technique (pas d'imprimante, etc.)

#### 2. Créer le Bon Climat

- "Il n'y a pas de mauvaise réponse, seulement des apprentissages"
- "L'erreur est NORMALE et SOUHAITABLE dans un jeu de rôle"
- "Ce qui se passe ici reste entre nous" (confidentialité)

#### 3. Gérer le Temps

- Être strict sur le timing (réalisme industriel)
- Mais : préférer un bon débriefing à un 2ème jeu bâclé
- Si retard : mieux vaut sauter un JdR que tous les faire mal

#### 4. Adapter au Public

**Public Débutant** (jamais fait de résolution de problème)

- Simplifier les scénarios
- Donner plus d'indices au départ
- Débriefing plus long et plus pédagogique

**Public Expérimenté** (déjà formés aux méthodes)

- Augmenter la difficulté (moins d'indices)
- Introduire des perturbations supplémentaires
- Débriefing axé sur les subtilités

#### 5. Rendre Concret

- Utiliser des vrais objets quand possible (composants, joints, etc.)
- Montrer des vidéos d'entreprises réelles
- Inviter un témoignage d'entreprise si possible
