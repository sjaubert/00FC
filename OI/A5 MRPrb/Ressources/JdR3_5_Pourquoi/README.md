# 🎭 JdR n°3 : Le "5 Pourquoi" du Mystère

**Méthode** : 5 Pourquoi  
**Niveau** : ⭐⭐ Intermédiaire  
**Durée** : 60 min (40 min jeu + 20 min débriefing)  
**Joueurs** : 4 personnes

---

## 🎬 Le Pitch

Des arrêts intempestifs d'un convoyeur surviennent de manière aléatoire (3-4 fois par semaine). Le service maintenance a déjà changé le moteur DEUX FOIS, mais le problème persiste. L'usine perd 2h de production à chaque arrêt (~15 000€/mois). Les techniciens commencent à croire que "ce convoyeur est hanté".

## 🎯 Le Piège

L'équipe va naturellement chercher des causes techniques complexes (roulements, alignement, moteur défectueux...). La vraie cause racine est simple : l'eau de nettoyage s'infiltre dans le coffret électrique mal fermé, créant des courts-circuits intermittents. Seuls les 5 Pourquoi appliqués rigoureusement permettront de remonter à la cause organisationnelle.
